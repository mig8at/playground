# tasks: el tablero de Miguel (qué tiene abierto y el plan de una tarea)

| comando | para qué |
|---|---|
| `make tasks` | las tareas abiertas: número, estado y título |
| `task 101` | una tarea entera, por número o por su slug: objetivo, dónde se toca, cómo se ataca, cómo se comprueba |

```command
make tasks
task 101
```

De una tarea llega sólo su `task.md`. Sus mediciones (la pila) no se leen desde acá.
