# tareas: el tablero de Miguel (qué tiene abierto y el plan de una tarea)

| comando | para qué |
|---|---|
| `make tareas` | las tareas abiertas: número, estado y título |
| `tarea 101` | una tarea entera, por número o por su slug: objetivo, dónde se toca, cómo se ataca, cómo se comprueba |

```comando
make tareas
tarea 101
```

De una tarea llega sólo su `task.md`. Sus mediciones (la pila) no se leen desde acá.
