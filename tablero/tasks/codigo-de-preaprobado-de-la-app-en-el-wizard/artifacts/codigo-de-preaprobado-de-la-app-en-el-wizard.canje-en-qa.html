Código de preaprobado

El cliente trae de la app un código que lo liga a un comercio y a una entidad. El asesor lo ingresa en la opción «Usuario app», la solicitud nace con ese cliente ya registrado y el listado muestra sólo la entidad del preaprobado. Esta página arma los pasos para probarlo en QA sin la app: generar el código, canjearlo en la pantalla y comprobar que quedó usado.

códigolo que ve el asesorpor qué, y qué hacer

        
          
—Llega al listado con una sola entidad
              Funcionó. La solicitud nace con el cliente del código y en estado inicial, y el código queda consumido.

          
CCO001«El código debe tener 2 letras y 4 números.»
              El formato no es válido. Hoy el servicio de QA emite 4 números; la pantalla acepta los dos formatos.

          
CCO002«No encontramos este punto de venta.»
              La sucursal del enlace no existe en ese ambiente.

          
CCO003«Ese código no está disponible: puede que no exista para este comercio o que ya se haya usado.»
              El caso normal es un código inexistente, ya usado, vencido o de otro comercio: un código sólo sirve donde se generó. ⚠ Pero si todos los códigos dan esto, el backend no llega al servicio de códigos y el problema es de configuración, no del código.

          
CCO004«Ese código no tiene una entidad asociada…»
              El código existe pero no dice qué entidad preaprobó.

          
CCO005«No pudimos validar el código…»
              Falló la creación de la solicitud. El código no se consume en ese caso: se puede reintentar.

          
CCO006«No se pudo confirmar el código. Intenta de nuevo en un momento.»
              El servicio no pudo marcar el código como usado. La solicitud se descarta y el código sigue disponible: se puede reintentar.

          
CCO007«No pudimos validar el código…»
              El usuario del código no existe en la base o le falta celular o correo.

        
      

    

  


  

    
Antes de reportar un fallo

    

      No aparece la opción «Usuario app»
      
Sólo se ofrece en comercios de Colombia: en otro país no aparece, y abrir la
         pantalla del código por su dirección te devuelve a la del celular. Es lo esperado. Para verlo, el
         comercio de pruebas de Perú (sucursal a8221e67) es el contraste.

    

    

      El listado muestra todas las entidades, no una
      
El recorte a una sola entidad vale para la solicitud que nació del código, y sólo en el mismo
         navegador donde se canjeó. Si la entidad del código no está habilitada en ese punto de venta, el
         listado muestra las de siempre. Elegí la entidad de la lista de esta página: son las habilitadas
         en esa sucursal.

    

    

      La pantalla me lleva a otro comercio
      
El asesor sólo entra a su propia sucursal: si tu usuario está asignado a otro punto de venta, la
         pantalla te lleva al tuyo. Generá el código para el comercio donde está tu asesor, o pedí que lo
         asignen al de la prueba.

    

    

      Cuánto vive un código
      
Hasta el último día del mes en que se generó. Mientras esté activo, volver a
         generarlo para el mismo cliente, comercio y entidad devuelve el mismo código; una vez canjeado,
         la próxima generación da uno nuevo.
